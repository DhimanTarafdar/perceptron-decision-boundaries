# Perceptron & Decision Boundary Mastery

এই রিপোজিটরিটিতে মেশিন লার্নিংয়ের অত্যন্ত মৌলিক বিষয় **Perceptron** এবং **Decision Boundary** নিয়ে বিস্তারিত আলোচনা এবং গাণিতিক সমস্যার সমাধান দেওয়া হয়েছে। এটি মূলত বাংলায় সহজভাবে লিনিয়ার ক্লাসিফিকেশন বোঝার একটি গাইড।

---

## Topics Covered
এই রিপোজিটরিটিতে আমরা নিচের বিষয়গুলো বিস্তারিতভাবে আলোচনা করেছি:

- **Perceptron Fundamentals:** পারসেপট্রনের সংজ্ঞা এবং এটি কীভাবে কাজ করে।
- **Decision Boundary:** একটি লিনিয়ার ক্লাসিফায়ার কীভাবে ডেটাকে আলাদা করে।
- **Bias & Weights:** ডিসিশন বাউন্ডারির অবস্থান (Position) এবং ওরিয়েন্টেশন (Orientation) পরিবর্তনে এদের ভূমিকা।
- **Mathematical Updates:** পারসেপট্রন লার্নিং রুল ব্যবহার করে ওয়েট এবং বায়াস আপডেট করার গাণিতিক পদ্ধতি।
- **Linear Separability:** কেন পারসেপট্রন XOR গেটের মতো নন-লিনিয়ার সমস্যা সমাধান করতে পারে না।

---

## Key Concepts Recap

### 1. Decision Boundary Equation
২-ডি স্পেসে একটি পারসেপট্রনের ডিসিশন বাউন্ডারি হলো:
$$w_1x_1 + w_2x_2 + b = 0$$

### 2. Weight Update Rule
যখন মডেল ভুল প্রেডিকশন করে, তখন আমরা এই সূত্রটি ব্যবহার করি:
- **New Weight:** $w_{new} = w_{old} + \eta(t - y)x$
- **New Bias:** $b_{new} = b_{old} + \eta(t - y)$
